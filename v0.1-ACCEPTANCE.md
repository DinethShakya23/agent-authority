## Scenario details

### S01 - Purchase order allowed (ALLOW, AI-0000)

**What happens:** An agent with `supplier.read` capability and a $50,000 budget
submits a $7,500 purchase order for vendor ACME.

**Test:** Runs the capability stage against a passport that grants `supplier.read`
and resource type `PurchaseOrder`. Then reserves $7,500 from a lease with $50,000
granted.

**Expected:** Capability check passes (Continue). Budget reservation succeeds.

**Verdict:** PASS

---

### S02 - Purchase order exceeds budget (DENY, AI-6001)

**What happens:** An agent attempts a $50,000 purchase order against a $25,000 budget.

**Test:** Creates a lease with `amount: "25000"` and attempts to reserve
`amount: "50000"`.

**Expected:** Reservation fails with `AI-6001` (budget exhausted).

**Verdict:** PASS

---

### S03 - Unapproved vendor (DENY, AI-5005)

**What happens:** An agent's passport restricts vendors to `["ACME"]` via
per-request constraints. A request arrives for a different vendor.

**Test:** Runs the constraints stage with per-request constraints defined but
no evaluator configured (nil predicates = fail-closed).

**Expected:** Deny with `AI-5005` (constraint failed).

**Verdict:** PASS

---

### S04 - Unauthorized capability (DENY, AI-5002)

**What happens:** An agent with only `supplier.read` attempts `supplier.delete`.

**Test:** Runs the capability stage checking for `supplier.delete` against a
passport that only grants `supplier.read`.

**Expected:** Deny with `AI-5002` (capability denied).

**Verdict:** PASS

---

### S05 - Expired passport (DENY, AI-2003)

**What happens:** A request arrives 5 minutes after the passport's `expiresAt`.

**Test:** Sets passport `expiresAt` to 5 minutes in the past, runs the validity
stage.

**Expected:** Deny with `AI-2003` (passport expired).

**Verdict:** PASS

---

### S06 - Replayed request (DENY, AI-4002)

**What happens:** The same nonce is submitted twice within the replay window.

**Test:** Creates a nonce cache with 30-second TTL. First request with
`nonce-replay-test-001` passes. Second request with the same nonce is rejected.

**Expected:** First request: Continue. Second request: Deny with `AI-4002`
(nonce reused).

**Verdict:** PASS

---

### S07 - Revoked passport (DENY, AI-2005)

**What happens:** A request carries a passport that has been revoked in the
control plane.

**Test:** Configures a stub revocation checker that marks the passport ID as
revoked. Runs the revocation stage.

**Expected:** Deny with `AI-2005` (passport revoked).

**Verdict:** PASS

---

### S08 - Wrong integration audience (DENY, AI-5001)

**What happens:** An agent's passport is scoped to
`https://other-system.example.com/api` but the request hits a firewall
protecting `https://sap.example.com/api`.

**Test:** Sets passport audience to a different URL than the integration's
audience. Runs the audience stage.

**Expected:** Deny with `AI-5001` (audience mismatch).

**Verdict:** PASS

---

### S09 - Budget exhaustion on third request (DENY, AI-6001)

**What happens:** An agent makes three $9,000 requests against a $25,000 budget.
The first two succeed ($18,000 consumed), the third would require $27,000 total.

**Test:** Creates a lease with `amount: "25000"`. Reserves and commits $9,000
twice. Third reservation for $9,000 fails.

**Expected:** First two reservations succeed. Third fails with `AI-6001`
(budget exhausted). Remaining $7,000 < $9,000 requested.

**Verdict:** PASS

---

### S10 - Call limit exceeded (DENY, AI-6002)

**What happens:** An agent makes 13 API calls against a limit of 12.

**Test:** Creates a lease with `calls: "12"`. Reserves and commits 12 calls
one at a time. The 13th reservation fails.

**Expected:** Calls 1-12 succeed. Call 13 fails with `AI-6002` (call limit).

**Verdict:** PASS

---

### S11 - Delegation monotonicity violation (DENY, AI-7001)

**What happens:** A parent passport with a $10,000 budget attempts to delegate
a child passport with $50,000.

**Test:** Constructs parent and child `AgentPassport` structs where child
`budget.amount = "50000"` exceeds parent `budget.amount = "10000"`. Calls
`delegation.CheckMonotonicity(parent, child)`.

**Expected:** Returns `AI-7001` (monotonicity violation). Invariant I6:
delegation chains narrow authority monotonically.

**Verdict:** PASS

---

### S12 - Tampered receipt chain (verify fails)

**What happens:** Two receipts are appended to a hash chain. The first receipt
is then tampered (decision mutated from `ALLOW` to `ALLOW_TAMPERED`, reason code
changed to `AI-0001`). The signature no longer matches.

**Test:** Generates an Ed25519 key, creates a receipt chain, appends two
receipts. Mutates the first receipt's `Decision` and `ReasonCode` fields
in-memory. Verifies the original signature is now invalid against the tampered
content.

**Expected:** Tampering is detectable. The Ed25519 signature was computed over
the original fields and does not cover the mutated values.

**Verdict:** PASS

---

### S13 - Token missing required scope (DENY, AI-5002)

**What happens:** An agent's passport has an empty capabilities list but the
firewall requires `supplier.read`.

**Test:** Sets passport capabilities to `[]`. Runs the capability stage checking
for `supplier.read`.

**Expected:** Deny with `AI-5002` (capability denied). The agent's token lacks
the required scope, so passport issuance would be gated at the control plane.

**Verdict:** PASS

---

### S14 - Agent disabled mid-execution (DENY, AI-2006)

**What happens:** An agent is suspended via SCIM2 sync while it has active
passports. The control plane bumps the agent's epoch from 2 to 3. The
outstanding passport was issued at epoch 2.

**Test:** Creates a passport with `epoch: 2`. Configures the firewall cache
with `agentEpoch: 3` for the agent. Runs the revocation stage.

**Expected:** Deny with `AI-2006` (passport epoch stale). The passport's epoch
is behind the agent's current epoch, meaning the agent was suspended after the
passport was issued.

**Verdict:** PASS
