# Roadmap

## v0.1 - the vertical slice (14 weeks)
WSO2 federation, Cedar policy, passport authority, budget leases, step-ca,
HTTP firewall, delegation, receipt chain, agentctl, SDK, 14 acceptance
scenarios, docs site.

## v0.2
MCP adapter, gRPC adapter, credential broker, HITL approval, etcd HA,
Envoy ext_authz mode, revocation streaming.

## v0.3
Offline delegation, multi-agent authorisation, second IdP (Keycloak) to prove
the `Federator` interface is vendor-neutral.

## v1.0
Stable API, multi-cluster, HA, production hardening, multiple independent
adopters.
