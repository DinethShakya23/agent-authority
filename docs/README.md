# Documentation

- `concepts/`        passport, budget, delegation, receipts, boundaries
- `getting-started/` role-specific paths: agent developer, platform operator, security reviewer
- `reference/`       API, CLI, error codes, configuration
- `operations/`      deployment, WSO2 integration, troubleshooting, security
- `adr/`             architecture decision records
- `REPORT.md`        the full technical report

CNCF documentation assessment looks for conceptual docs, complete API/CLI
reference, role-specific getting-started paths, and task-oriented instructions.
This layout maps to that directly.
