# Security Policy

## Reporting

Report vulnerabilities privately to **security@agentauthority.dev** (or via
GitHub private vulnerability reporting). Do not open a public issue.

Acknowledgement within 3 working days; assessment within 10; coordinated
disclosure by default.

## Scope

In scope: passport forgery, signature bypass, replay, budget overspend,
delegation escalation, receipt forgery, tenant crossing, fail-open behaviour.

Out of scope: actions taken by an agent that are fully within its granted
authority - that is the documented boundary of the security claim.

## Supported versions

Pre-1.0: only the latest minor release receives fixes.
