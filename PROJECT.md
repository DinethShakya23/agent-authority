# Agent Integrator - project definition

> A cloud-native control plane and data plane that converts externally
> authenticated agent identity into short-lived, cryptographically verifiable,
> execution-scoped and budget-limited authority, and enforces that authority at
> enterprise integration boundaries.

Lifecycle: IDENTIFY -> AUTHORIZE -> ISSUE -> PROVE -> ENFORCE -> METER ->
INTEGRATE -> AUDIT
